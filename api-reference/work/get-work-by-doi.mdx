---
title: "Buscar un producto por DOI"
api: "GET https://api.dev.impactu.colav.co/work"
description: "Devuelve los productos bibliográficos que coinciden con un DOI."
---

## Parámetros de consulta

<ParamField query="doi" type="string" required>
  DOI completo del producto. Ejemplo:
  `https://doi.org/10.18316/2318-8081.15.1`.
</ParamField>

<Note>
  La respuesta es una lista porque un mismo DOI puede estar asociado a más de
  un registro en la base de datos. En la mayoría de casos devuelve un solo
  elemento. Si no se proporciona el parámetro `doi`, el endpoint devuelve un
  error `401`.
</Note>

## Respuesta

<ResponseField name="data" type="object[]">
  Lista de productos que coinciden con el DOI. La estructura de cada producto
  es la misma que en [Obtener un producto](/api-reference/work/get-work).
</ResponseField>
