---
title: "Obtener un producto"
api: "GET https://api.dev.impactu.colav.co/work/{work_id}"
description: "Devuelve un producto bibliográfico a partir de su identificador."
---

import ViewParam from "/snippets/view-param.mdx";
import EntityMeta from "/snippets/entity-meta.mdx";

## Parámetros de ruta

<ParamField path="work_id" type="string" required>
  Identificador del producto. Ejemplo: `6ab4ac4e5418a51e324cc06a`.
</ParamField>

## Parámetros de consulta

<ViewParam />

No recibe parámetros de paginación ni de filtro.

## Respuesta

<ResponseField name="data" type="object">
  El producto solicitado.
  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Identificador del producto.
    </ResponseField>
    <ResponseField name="title" type="string">
      Título principal.
    </ResponseField>
    <ResponseField name="titles" type="object[]">
      Títulos por fuente (`title`, `lang`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="subtitle" type="string | null">
      Subtítulo.
    </ResponseField>
    <ResponseField name="language" type="string">
      Idioma (código ISO 639-1).
    </ResponseField>
    <ResponseField name="year_published" type="integer">
      Año de publicación.
    </ResponseField>
    <ResponseField name="date_published" type="integer | null">
      Fecha de publicación en segundos Unix.
    </ResponseField>
    <ResponseField name="doi" type="string | null">
      DOI completo (por ejemplo `https://doi.org/10.1000/xyz`).
    </ResponseField>
    <ResponseField name="keywords" type="array">
      Palabras clave.
    </ResponseField>
    <ResponseField name="abstract" type="string | null">
      Resumen principal en texto.
    </ResponseField>
    <ResponseField name="authors" type="object[]">
      Todos los autores del producto, en orden de firma (10 con
      `view=summary`), con sus afiliaciones, identificadores externos,
      clasificaciones y datos demográficos disponibles. Ver [Autores de los productos](/guides/authorship).
    </ResponseField>
    <ResponseField name="authors_count" type="integer">
      Cantidad de autores.
    </ResponseField>
    <ResponseField name="groups" type="object[]">
      Grupos de investigación asociados, con sus citas y clasificaciones.
    </ResponseField>
    <ResponseField name="product_types" type="object[]">
      Tipos de producto por fuente (`name`, `source`).
    </ResponseField>
    <ResponseField name="types" type="object[]">
      Tipos por fuente con nivel y clasificación.
    </ResponseField>
    <ResponseField name="ranking" type="object[]">
      Clasificaciones del producto (por ejemplo, de Minciencias).
    </ResponseField>
    <ResponseField name="source" type="object">
      Fuente (revista u otro tipo) donde se publicó. Incluye `id`, `name`,
      `names`, `types`, `external_ids`, `external_urls`, `ranking`,
      `publisher`, `apc`, `scimago_quartile` y `updated`.
    </ResponseField>
    <ResponseField name="bibliographic_info" type="object">
      Información bibliográfica: `volume`, `issue`, `start_page`, `end_page`,
      `pages` y `bibtex`.
    </ResponseField>
    <ResponseField name="bibtex" type="string | null">
      Entrada BibTeX.
    </ResponseField>
    <ResponseField name="volume" type="string | integer | null">
      Volumen. Copia de `bibliographic_info.volume`.
    </ResponseField>
    <ResponseField name="pages" type="string | null">
      Páginas. Copia de `bibliographic_info.pages`.
    </ResponseField>
    <ResponseField name="start_page" type="string | null">
      Página inicial. Copia de `bibliographic_info.start_page`.
    </ResponseField>
    <ResponseField name="end_page" type="string | null">
      Página final. Copia de `bibliographic_info.end_page`.
    </ResponseField>
    <ResponseField name="publisher" type="string | null">
      Nombre de la editorial.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citas por fuente (`count`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="citations_by_year" type="object[]">
      Citas por año (`year`, `cited_by_count`).
    </ResponseField>
    <ResponseField name="open_access" type="object">
      Estado de acceso abierto: `is_open_access`, `open_access_status`,
      `url` y `has_repository_fulltext`.
    </ResponseField>
    <ResponseField name="apc" type="object">
      Información de APC: `charges`, `currency` y `paid`.
    </ResponseField>
    <ResponseField name="primary_topic" type="object">
      Tópico principal con su subfield, field y domain (OpenAlex).
    </ResponseField>
    <ResponseField name="topics" type="object[]">
      Tópicos asociados.
    </ResponseField>
    <ResponseField name="subjects" type="object[]">
      Áreas de conocimiento agrupadas por fuente.
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      Identificadores externos.
    </ResponseField>
    <ResponseField name="external_urls" type="object[]">
      Enlaces externos: DOI, Scholar, acceso abierto, etc.
    </ResponseField>
    <ResponseField name="references" type="array">
      Referencias bibliográficas.
    </ResponseField>
    <ResponseField name="references_count" type="integer | null">
      Cantidad de referencias.
    </ResponseField>
    <ResponseField name="updated" type="object[]">
      Última actualización por fuente (`source`, `time` en segundos Unix).
    </ResponseField>
  </Expandable>
</ResponseField>
