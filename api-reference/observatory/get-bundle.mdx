---
title: "Datos de un tablero"
api: "GET https://api.dev.impactu.colav.co/observatories/{slug}/boards/{board}/bundle"
description: "Devuelve en un solo JSON todos los datos que necesita un tablero de un observatorio."
---

<Note>
  Los observatorios leen tablas precalculadas en ClickHouse (`obs_*`). Sin
  ClickHouse configurado, o sin esas tablas cargadas, el endpoint responde
  `503`. No requiere autenticación.
</Note>

## Parámetros de ruta

<ParamField path="slug" type="string" required>
  Observatorio. Hoy solo existe `vri-udea`, el de la Vicerrectoría de
  Investigación de la Universidad de Antioquia.
</ParamField>

<ParamField path="board" type="integer" required>
  Tablero: `1` (Masa crítica temática), `2` (Colaboración, redes y hélices) o
  `3` (Capacidades de base UdeA).
</ParamField>

## Caché y compresión

La respuesta pesa entre 5,8 y 8,3 MB sin comprimir, y cerca de 1,3 MB con gzip.

- **`ETag`:** la respuesta trae un `ETag` que solo cambia con cada carga de datos, por ejemplo `"20261107-c550a33072f7"`. Envíalo en `If-None-Match`: si los datos no cambiaron, la respuesta es `304` sin cuerpo.
- **gzip:** con `Accept-Encoding: gzip` el cuerpo llega comprimido (`Content-Encoding: gzip`).
- `Cache-Control: no-cache` obliga a revalidar con el `ETag` en cada uso.

## Respuesta

Un objeto JSON con las tablas del tablero. Las claves dependen del tablero; no llevan envoltorio `data`.

| Tablero | Claves |
| --- | --- |
| `1` | `meta`, `topics`, `facs`, `deps`, `deps_fac`, `cens`, `groups`, `ejes`, `facts`, `pies`, `subregiones`, `actores`, `obs`, `ods`, `agendas` |
| `2` | `tipos`, `sectors`, `sectorsEs`, `subfields`, `sfField`, `fields`, `facs`, `deps`, `deps_fac`, `countries`, `regions`, `depts`, `groups`, `centros`, `insts`, `subregs`, `works`, `projects`, `thesaurus`, `patentes`, `registro_grupos`, `metas`, `doms`, `graph`, `ext` |
| `3` | `doms`, `fields`, `subs`, `sub_meta`, `tops`, `top_meta`, `facs`, `deps`, `deps_fac`, `groups`, `centros`, `agendas`, `agendas_all`, `tipos`, `tesis_sub`, `ambitos`, `inst`, `P`, `A`, `age_bins`, `proj`, `creacion`, `metas`, `talent`, `artes`, `pi`, `registro_grupos`, `ext` |
