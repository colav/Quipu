---
title: "Desactivar usuario"
api: "DELETE https://api.dev.impactu.colav.co/admin/users/{email}"
description: "Desactiva una cuenta de usuario (is_active = false). No elimina el registro."
---

<Note>
  Requiere sesión activa con rol `admin`. La cuenta queda desactivada pero no
  se borra. Un usuario desactivado no puede iniciar sesión. Para reactivarla
  usa [Activar usuario](/api-reference/users/activate-user).
</Note>

## Parámetros de ruta

<ParamField path="email" type="string" required>
  Correo electrónico del usuario a desactivar.
</ParamField>

## Respuesta

<ResponseField name="success" type="boolean">
  `true` si la desactivación fue exitosa.
</ResponseField>

<ResponseField name="msg" type="string">
  Mensaje de confirmación o error.
</ResponseField>

<ResponseExample>
```json 200
{ "success": true, "msg": "Usuario desactivado correctamente." }
```

```json 404
{ "success": false, "msg": "Usuario no encontrado." }
```

```json 401
{ "success": false, "msg": "Token no proporcionado o inválido. Por favor, inicia sesión nuevamente." }
```

```json 403
{ "success": false, "msg": "Permiso denegado: No pueden realizar esta acción." }
```
</ResponseExample>
