---
title: "Restablecer contraseña"
api: "PATCH https://api.dev.impactu.colav.co/admin/users/{email}"
description: "Genera una nueva contraseña aleatoria para el usuario y la envía por correo electrónico."
---

<Note>
  Requiere sesión activa con rol `admin`. No se envía ningún cuerpo en la
  solicitud. La nueva contraseña se envía al correo del usuario.
</Note>

## Parámetros de ruta

<ParamField path="email" type="string" required>
  Correo electrónico del usuario al que se le restablecerá la contraseña.
</ParamField>

## Respuesta

<ResponseField name="success" type="boolean">
  `true` si la contraseña fue restablecida y el correo enviado.
</ResponseField>

<ResponseField name="msg" type="string">
  Mensaje de confirmación o error.
</ResponseField>

<ResponseExample>
```json 200
{ "success": true, "msg": "La contraseña de usuario@example.com se actualizó correctamente." }
```

```json 404
{ "success": false, "msg": "El usuario con correo usuario@example.com no fue encontrado" }
```

```json 403 — cuenta desactivada
{ "success": false, "msg": "Cuenta desactivada para el usuario usuario@example.com" }
```

```json 401
{"msg": "Token no proporcionado o inválido. Por favor, inicia sesión nuevamente.", "success": false}
```

```json 403
{ "success": false, "msg": "Permiso denegado: No pueden realizar esta acción." }
```
</ResponseExample>
