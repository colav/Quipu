---
title: "Activar usuario"
api: "PATCH https://api.dev.impactu.colav.co/admin/users/{email}/restore"
description: "Reactiva una cuenta de usuario previamente desactivada (is_active = true)."
---

<Note>
  Requiere sesión activa con rol `admin`.
</Note>

## Parámetros de ruta

<ParamField path="email" type="string" required>
  Correo electrónico del usuario a activar.
</ParamField>

## Respuesta

<ResponseField name="success" type="boolean">
  `true` si la activación fue exitosa.
</ResponseField>

<ResponseField name="msg" type="string">
  Mensaje de confirmación o error.
</ResponseField>

<ResponseExample>
```json 200
{ "success": true, "msg": "El usuario usuario@example.com ha sido activado." }
```

```json 404
{ "success": false, "msg": "Usuario con correo usuario@example.com no encontrado" }
```

```json 401
{"msg": "Token no proporcionado o inválido. Por favor, inicia sesión nuevamente.", "success": false}
```

```json 403
{ "success": false, "msg": "Permiso denegado: No pueden realizar esta acción." }
```
</ResponseExample>
