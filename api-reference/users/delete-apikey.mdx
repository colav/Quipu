---
title: "Eliminar API Key"
api: "DELETE https://api.dev.impactu.colav.co/users/{email}/apikey"
description: "Elimina el API Key asociado al usuario autenticado."
---

<Note>
  El usuario autenticado solo puede eliminar su propio API Key.
</Note>

## Parámetros de ruta

<ParamField path="email" type="string" required>
  Correo electrónico del usuario. Debe coincidir con el usuario autenticado.
</ParamField>

## Respuesta

<ResponseField name="success" type="boolean">
  `true` si el API Key fue eliminado correctamente.
</ResponseField>

<ResponseField name="msg" type="string">
  Mensaje de confirmación o error.
</ResponseField>

<ResponseExample>
```json 200
{ "success": true, "msg": "API Key eliminado correctamente." }
```

```json 404
{ "success": false, "msg": "Usuario no encontrado." }
```

```json 401
{ "success": false, "msg": "Token no proporcionado o inválido. Por favor inicia sesión nuevamente." }
```

```json 403
{ "success": false, "msg": "No tienes permiso para eliminar el API Key de otro usuario." }
```
</ResponseExample>
