title: "Autores de una patente"

description: "Devuelve la lista de autores de una patente."
---

import EntityMeta from "/snippets/entity-meta.mdx";

## Parámetros de ruta

<ParamField path="patent_id" type="string" required>
  Identificador de la patente. Ejemplo: `6ab847915418a51e32855aa6`.
</ParamField>

## Parámetros de consulta

<ParamField query="view" type="string" default="full">
  Nivel de detalle. Con `summary`, cada autor trae solo `id`, `full_name`,
  `type` y `affiliations`, y se omiten los campos sin dato.
</ParamField>

La lista de autores también está en el campo `authors` de [Obtener una patente](/api-reference/patent/get-patent).

## Respuesta

<ResponseField name="data" type="object[]">
  Lista de autores de la patente. La estructura de cada autor es la misma que
  en [Autores de un producto](/api-reference/work/get-work-authors).
</ResponseField>
