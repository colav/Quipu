---
title: "Iniciar sesión"
api: "POST https://api.dev.impactu.colav.co/login"
description: "Autentica con email y contraseña. Si es válido, establece una cookie HttpOnly con el JWT de sesión."
---

## Cuerpo de la solicitud

<ParamField body="email" type="string" required>
  Correo electrónico del usuario.
</ParamField>

<ParamField body="password" type="string" required>
  Contraseña del usuario.
</ParamField>

<Note>
  El JWT **no** se devuelve en el cuerpo de la respuesta. Se establece
  automáticamente como cookie HttpOnly `access_token_cookie`. Las llamadas
  posteriores a endpoints protegidos deben incluir esta cookie.
</Note>

## Respuesta

<ResponseField name="success" type="boolean">
  `true` si la autenticación fue exitosa.
</ResponseField>

<ResponseField name="_id" type="string">
  Identificador ROR de la institución asociada al usuario.
</ResponseField>

<ResponseField name="institution" type="string">
  Nombre de la institución.
</ResponseField>

<ResponseField name="role" type="string">
  Rol del usuario en la plataforma (`admin`, `staff`, etc.).
</ResponseField>

<ResponseExample>
```json 200
{
  "success": true,
  "_id": "example-institution-id",
  "institution": "Universidad Ejemplo",
  "role": "staff"
}
```

```json 400
{"msg": "correo y contraseña requeridos", "success": false}
```

```json 401
{"msg": "Usuario con correo usuario@example.com no encontrado o contraseña no conciden", "success": false}
```

```json 403
{ "success": false, "msg": "El usuario está desactivado. Contacte al administrador del sistema" }
```
</ResponseExample>
