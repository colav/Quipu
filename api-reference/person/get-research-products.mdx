description: "Lista de forma paginada los productos de investigación de un autor, o devuelve uno de sus indicadores con el parámetro plot."
---

Este endpoint tiene dos modos:

- **Listado de productos** (sin `plot`): devuelve los productos del autor con paginación, orden y filtros.
- **Indicadores** (con `plot`): devuelve los datos de un indicador del autor. Consulta el [catálogo de indicadores](/api-reference/person/plots/overview).

## Parámetros de ruta

<ParamField path="person_id" type="string" required>
  Identificador del autor. Ejemplo: `0000000001`.
</ParamField>

## Parámetros de consulta

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Ordenamiento con el formato `campo_direccion`, donde la dirección es `asc` o
  `desc`. Campos para productos: `citations`, `alphabetical` (por título) y
  `year` (año de publicación). Ejemplo: `year_desc`.
</ParamField>

<ParamField query="view" type="string" default="full">
  Nivel de detalle de la respuesta: `full` o `summary`. Con `summary`, la lista
  de autores de cada producto se recorta a 10.
</ParamField>

<ParamField query="fields" type="string">
  Campos de primer nivel que quieres recibir, separados por coma. No admite
  campos anidados. Campos permitidos: `id`, `authors`, `titles`, `keywords`,
  `topics`, `subjects`, `source`, `types`, `year_published`,
  `citations_by_year`, `citations_count` y `updated`. Ejemplo:
  `fields=authors,titles`.
</ParamField>

<ParamField query="plot" type="string">
  Nombre del indicador a devolver. Con este parámetro la respuesta es el
  indicador, sin paginación. Consulta el [catálogo de
  indicadores](/api-reference/person/plots/overview).
</ParamField>

### Filtros

Los mismos filtros de [Buscar productos](/api-reference/search/works). También aplican a los indicadores.

<WorksFilterParams />

Las opciones válidas se consultan en [Filtros de productos de un autor](/api-reference/person/get-research-products-filters).

<Note>
  Si no envías `max`, `page` ni `sort`, se aplican `max=10`, `page=1` y
  `sort=citations_desc`. Si envías `max` y `page` sin `sort`, se aplica
  `sort=citations_desc`.
</Note>

## Respuesta del listado

La estructura de cada producto es idéntica a la de [Productos de una afiliación](/api-reference/affiliation/get-research-products).
