## Respuesta

Archivo Excel adjunto:

- `Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- Nombre de archivo: `source_works.xlsx`

Nombre de archivo `source_works.xlsx`, con las siguientes columnas:

<WorksExportColumns />

Con las siguientes columnas adicionales:

| Columna            | Descripción                                                         |
| ------------------ | ------------------------------------------------------------------- |
| `scimago_quartile` | Cuartil Scimago de la fuente en el año de publicación del producto. |
