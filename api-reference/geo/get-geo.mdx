title: "Obtener entidad geográfica"
api: "GET https://api.dev.impactu.colav.co/geo/{geo_type}/{geo_id}"
description: "Devuelve una entidad geográfica (departamento o ciudad) a partir de su código DANE."
---

import EntityMeta from "/snippets/entity-meta.mdx";

## Parámetros de ruta

<ParamField path="geo_type" type="string" required>
  Tipo de entidad geográfica. Valores permitidos: `state` (departamento) o `city` (ciudad).
</ParamField>

<ParamField path="geo_id" type="string" required>
  Código DANE de la entidad. Ejemplos: `05` para Antioquia (state), `05001`
  para Medellín (city).
</ParamField>

No recibe parámetros de consulta: `view` no aplica a las entidades geográficas.

## Respuesta

<ResponseField name="data" type="object">
  La entidad geográfica solicitada.
  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Código DANE de la entidad.
    </ResponseField>
    <ResponseField name="name" type="string">
      Nombre de la entidad.
    </ResponseField>
    <ResponseField name="type" type="string">
      Tipo: `state` o `city`.
    </ResponseField>
    <ResponseField name="country" type="string">
      País al que pertenece.
    </ResponseField>
    <ResponseField name="country_code" type="string">
      Código ISO 3166-1 alpha-2 del país.
    </ResponseField>
    <ResponseField name="state" type="object | null">
      Departamento al que pertenece la ciudad (`id`, `name`). Solo presente
      cuando `geo_type` es `city`.
    </ResponseField>
    <ResponseField name="latitude" type="number | null">
      Latitud. Solo presente cuando `geo_type` es `city`.
    </ResponseField>
    <ResponseField name="longitude" type="number | null">
      Longitud. Solo presente cuando `geo_type` es `city`.
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      Identificadores externos (`id`, `source`). Por ejemplo, el código DANE.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citas totales de los productos asociados, por fuente (`count`, `source`).
    </ResponseField>
    <ResponseField name="products_count" type="integer">
      Número de productos bibliográficos asociados.
    </ResponseField>
    <ResponseField name="authors_count" type="integer">
      Número de autores asociados.
    </ResponseField>
    <ResponseField name="institutions_count" type="integer">
      Número de instituciones asociadas.
    </ResponseField>
    <ResponseField name="groups_count" type="integer">
      Número de grupos de investigación asociados.
    </ResponseField>
    <ResponseField name="cities_count" type="integer | null">
      Número de ciudades asociadas. Solo presente cuando `geo_type` es `state`.
    </ResponseField>
  </Expandable>
</ResponseField>

<EntityMeta />

Las instituciones, los grupos y, en los departamentos, las ciudades se consultan en [Afiliaciones de una entidad geográfica](/api-reference/geo/get-geo-affiliations).
