description: "Devuelve los productos bibliográficos asociados a un departamento o ciudad, con paginación y ordenamiento."
---

## Parámetros de ruta

<ParamField path="geo_type" type="string" required>
  Tipo de entidad geográfica. Valores permitidos: `state` o `city`.
</ParamField>

<ParamField path="geo_id" type="string" required>
  Código DANE de la entidad. Ejemplos: `05` para Antioquia, `05001` para
  Medellín.
</ParamField>

## Parámetros de consulta

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Ordenamiento con el formato `campo_direccion`, donde la dirección es `asc` o
  `desc`. Campos para productos: `citations`, `alphabetical` (por título) y
  `year` (año de publicación). Ejemplo: `year_desc`.
</ParamField>

<ViewParam />

<FieldsParam />

### Filtros

Los mismos filtros de [Buscar productos](/api-reference/search/works). Todos aceptan varios valores separados por coma.

<WorksFilterParams />

<Note>
  Si no envías `max`, `page` ni `sort`, se aplican `max=10`, `page=1` y
  `sort=citations_desc`. Si envías `max` y `page` sin `sort`, se aplica
  `sort=citations_desc`.
</Note>

## Respuesta

<ResponseField name="data" type="object[]">
  Lista de productos. La estructura de cada producto es la misma que en
  [Productos de una afiliación](/api-reference/affiliation/get-research-products).
</ResponseField>
