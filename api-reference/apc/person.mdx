---
title: "APC por autor"
api: "GET https://api.dev.impactu.colav.co/apc/person/{person_id}"
description: "Exporta un CSV con datos de APC de los productos bibliográficos de un autor."
---

## Parámetros de ruta

<ParamField path="person_id" type="string" required>
  Identificador del autor. Ejemplo: `0000000001`.
</ParamField>

<Note>
  Este endpoint devuelve un archivo CSV (`Content-Type: text/csv`), no JSON. El nombre del archivo
  descargado es `person.csv`.
</Note>

## Respuesta

El cuerpo de la respuesta es un archivo CSV con las siguientes columnas. Si la entidad no existe o no tiene productos, el archivo solo trae la fila de encabezados.

| Columna | Descripción |
| --- | --- |
| `work_doi` | DOI del producto. |
| `work_title` | Título del producto. |
| `source_name` | Nombre de la revista o fuente. |
| `source_apc_value` | Costo APC publicado por la revista. |
| `source_apc_currency` | Moneda del costo de la revista. |
| `work_apc_value` | Costo APC realmente pagado por este producto. |
| `work_apc_currency` | Moneda del pago real. |

<Note>
  Los campos de costo y moneda pueden estar vacíos cuando la información no
  está disponible en la base de datos.
</Note>

<ResponseExample>
```csv 200
work_doi,work_title,source_name,source_apc_value,source_apc_currency,work_apc_value,work_apc_currency
,An Image Processing System for Char Reactivity Analysis during Coal Combustion,,,,,
,Ontology-based Automatic Reclassification of Tissues and Organs in Histological Images,,,,,
```
</ResponseExample>
