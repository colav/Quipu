---
title: "APC por afiliación"
api: "GET https://api.dev.impactu.colav.co/apc/affiliation/{affiliation_id}"
description: "Exporta un CSV con datos de APC de los productos bibliográficos de una institución o grupo de investigación."
---

## Parámetros de ruta

<ParamField path="affiliation_id" type="string" required>
  Identificador de la institución o grupo. Ejemplos: `03bp5hc83` (Universidad
  de Antioquia), `COL0000000` (grupo de investigación).
</ParamField>

<Note>
  Este endpoint devuelve un archivo CSV, no JSON. El nombre del archivo
  descargado es `affiliation.csv`.
</Note>

## Respuesta

El cuerpo de la respuesta es un archivo CSV con las siguientes columnas:

| Columna | Descripción |
| --- | --- |
| `work_doi` | DOI del producto. |
| `work_title` | Título del producto. |
| `source_name` | Nombre de la revista o fuente. |
| `source_apc_value` | Costo APC publicado por la revista. |
| `source_apc_currency` | Moneda del costo de la revista. |
| `work_apc_value` | Costo APC realmente pagado por este producto. |
| `work_apc_currency` | Moneda del pago real. |

<Note>
  Los campos de costo y moneda pueden estar vacíos cuando la información no
  está disponible en la base de datos.
</Note>

<ResponseExample>
```csv 200
work_doi,work_title,source_name,source_apc_value,source_apc_currency,work_apc_value,work_apc_currency
https://doi.org/10.0000/ejemplo.001,Título del artículo,Revista Ejemplo,1500,USD,,
,Producto sin DOI ni datos APC,,,,,
```

```json 400
{ "error": "mensaje de error" }
```
</ResponseExample>
