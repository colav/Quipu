---
title: "Afiliaciones relacionadas"
api: "GET https://api.dev.impactu.colav.co/affiliation/{affiliation_type}/{affiliation_id}/affiliations"
description: "Devuelve las facultades, departamentos, grupos y autores asociados a una afiliación."
---

## Parámetros de ruta

<ParamField path="affiliation_type" type="string" required>
  Tipo de afiliación: `institution`, `faculty`, `department` o `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Identificador de la afiliación. Ejemplos: `03bp5hc83` (institución),
  `03bp5hc83_2` (facultad), `03bp5hc83_2_21620001_3153` (departamento),
  `COL0000407` (grupo).
</ParamField>

<Note>
  Este endpoint no recibe parámetros de consulta. A diferencia de [Obtener una
  afiliación](/api-reference/affiliation/get-affiliation), la respuesta no está
  envuelta en `data`.
</Note>

## Respuesta

La respuesta es un objeto cuyas listas dependen del tipo de afiliación consultada:

| `affiliation_type` | `faculties` | `departments` | `groups` | `authors` |
| ------------------ | :---------: | :-----------: | :------: | :-------: |
| `institution`      |     ✅      |      ✅       |    ✅    |           |
| `faculty`          |             |      ✅       |    ✅    |    ✅     |
| `department`       |             |               |    ✅    |    ✅     |
| `group`            |             |               |          |    ✅     |

Una institución sin facultades ni departamentos también incluye `authors`. Si la afiliación no existe, o el tipo no es uno de los cuatro, la respuesta es `200` con las listas vacías.

<ResponseField name="faculties" type="object[]">
  Facultades de la institución.
  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Identificador de la facultad.
    </ResponseField>
    <ResponseField name="name" type="string">
      Nombre.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="departments" type="object[]">
  Departamentos. Misma estructura que `faculties`.
</ResponseField>

<ResponseField name="groups" type="object[]">
  Grupos de investigación. Misma estructura que `faculties`.
</ResponseField>

<ResponseField name="authors" type="object[]">
  Autores asociados.
  <Expandable title="propiedades">
    <ResponseField name="id" type="string">
      Identificador del autor.
    </ResponseField>
    <ResponseField name="full_name" type="string">
      Nombre completo.
    </ResponseField>
  </Expandable>
</ResponseField>
