title: "Productos de una afiliación"

description: "Lista de forma paginada los productos de investigación de una afiliación, o devuelve uno de sus indicadores con el parámetro plot."
---

Este endpoint tiene dos modos:

- **Listado de productos** (sin `plot`): devuelve los productos de la afiliación, con paginación, orden y filtros.
- **Indicadores** (con `plot`): devuelve los datos de un indicador de la afiliación. Consulta el [catálogo de indicadores](/api-reference/affiliation/plots/overview).

## Parámetros de ruta

<ParamField path="affiliation_type" type="string" required>
  Tipo de afiliación: `institution`, `faculty`, `department` o `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Identificador de la afiliación. Ejemplos: `03bp5hc83` (institución),
  `03bp5hc83_20` (facultad).
</ParamField>

## Parámetros de consulta

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Ordenamiento con el formato `campo_direccion`, donde la dirección es `asc` o
  `desc`. Campos para productos: `citations`, `alphabetical` (por título) y
  `year` (año de publicación). Ejemplo: `year_desc`.
</ParamField>

<ViewParam />

<FieldsParam />

<ParamField query="plot" type="string">
  Nombre del indicador a devolver. Con este parámetro la respuesta es el
  indicador, sin paginación. Consulta el [catálogo de
  indicadores](/api-reference/affiliation/plots/overview).
</ParamField>

### Filtros

Los mismos filtros de [Buscar productos](/api-reference/search/works). También aplican a los indicadores. Todos aceptan varios valores separados por coma.

<WorksFilterParams />

Las opciones válidas se consultan en [Filtros de productos de una afiliación](/api-reference/affiliation/get-research-products-filters).

<Note>
  Si no envías `max`, `page` ni `sort`, se aplican `max=10`, `page=1` y
  `sort=citations_desc`. Si envías `max` y `page` sin `sort`, se aplica
  `sort=citations_desc`.
</Note>

## Respuesta del listado

    </ResponseField>

      Título principal.
    </ResponseField>
    <ResponseField name="titles" type="object[]">
      Títulos por fuente (`title`, `lang`, `source`).
    </ResponseField>
    <ResponseField name="abstracts" type="object[]">
      Resúmenes por fuente.
    </ResponseField>
    <ResponseField name="year_published" type="integer">
      Año de publicación.
    </ResponseField>
    <ResponseField name="language" type="string">
      Idioma.
    </ResponseField>
    <ResponseField name="doi" type="string">
      DOI.
    </ResponseField>
    <ResponseField name="keywords" type="string[]">
      Palabras clave.
    </ResponseField>
    <ResponseField name="authors" type="object[]">
      Autores con sus afiliaciones y clasificaciones (`id`, `full_name`,
      `first_names`, `last_names`, `affiliations`, `ranking`, `external_ids`).
    </ResponseField>
    <ResponseField name="authors_count" type="integer">
      Cantidad de autores.
    </ResponseField>
    <ResponseField name="groups" type="object[]">
      Grupos de investigación asociados, con sus citas y clasificaciones.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citas por fuente.
    </ResponseField>
    <ResponseField name="citations_by_year" type="object[]">
      Citas por año.
    </ResponseField>
    <ResponseField name="bibliographic_info" type="object">
      Volumen, número y páginas.
    </ResponseField>
    <ResponseField name="source" type="object">
      Fuente (revista) donde se publicó.
    </ResponseField>
    <ResponseField name="open_access" type="object">
      Estado de acceso abierto.
    </ResponseField>
    <ResponseField name="apc" type="object">
      Información de APC.
    </ResponseField>
    <ResponseField name="product_types" type="object[]">
      Tipos de producto (`name`, `source`).
    </ResponseField>
    <ResponseField name="types" type="object[]">
      Tipos por fuente, con su nivel.
    </ResponseField>
    <ResponseField name="ranking" type="object[]">
      Clasificaciones del producto (por ejemplo, de Minciencias).
    </ResponseField>
    <ResponseField name="primary_topic" type="object">
      Tópico principal.
    </ResponseField>
    <ResponseField name="topics" type="object[]">
      Tópicos.
    </ResponseField>
    <ResponseField name="subjects" type="object[]">
      Áreas de conocimiento.
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      Identificadores externos.
    </ResponseField>
    <ResponseField name="external_urls" type="object[]">
      Enlaces externos.
    </ResponseField>
    <ResponseField name="references" type="array">
      Referencias.
    </ResponseField>
    <ResponseField name="updated" type="object[]">
      Última actualización por fuente.
    </ResponseField>
  </Expandable>
</ResponseField>
