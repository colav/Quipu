Returns the values you can use in the filters of [Author products](/en/api-reference/person/get-research-products). They are the same filters as [Search products](/en/api-reference/search/works-filters), but computed only over the products of the given author.

The options and their counts depend on the filters you send: if you apply a filter, only the options that exist within that result are returned.

## Path parameters

<ParamField path="person_id" type="string" required>
  Author identifier. Example: `0000000001`.
</ParamField>

## Query parameters

All are optional. They accept several values separated by commas.
