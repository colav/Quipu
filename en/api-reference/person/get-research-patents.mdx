## Path parameters

<ParamField path="person_id" type="string" required>
  Author identifier. Example: `0000000001`.
</ParamField>

## Query parameters

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Sort with the format `field_direction`. Available fields:
  `citations`, `alphabetical` and `year`. Example: `year_desc`.
</ParamField>

<ViewParam />

<Note>
  The response structure is identical to that of [Affiliation patents](/en/api-reference/affiliation/get-research-patents).
</Note>
