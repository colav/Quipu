Citations per year. Chart type: **Bar**.

## Parameters

<ParamField path="person_id" type="string" required>
  Author identifier.
</ParamField>

<ParamField query="plot" type="string" required>
  Must be `annual_citation_count`.
</ParamField>

It also accepts the [product filters](/en/api-reference/person/get-research-products). `max`, `page` and `sort` do not apply.

## Response

The response structure is identical to that of the equivalent indicator for [affiliations](/en/api-reference/affiliation/plots/overview).
