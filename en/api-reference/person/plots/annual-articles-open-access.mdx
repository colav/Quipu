Open access articles per year. Chart type: **Bar**.

## Parameters

<ParamField path="person_id" type="string" required>
  Author identifier.
</ParamField>

<ParamField query="plot" type="string" required>
  Must be `annual_articles_open_access`.
</ParamField>

It also accepts the [product filters](/en/api-reference/person/get-research-products). `max`, `page` and `sort` do not apply.
