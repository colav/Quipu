Co-authorship network between the author and their most frequent collaborators. Chart type: **Network**.

Nodes represent authors. Edges represent collaborations (co-authorships). At most the 50 nodes with the highest degree are returned.

## Parameters

<ParamField path="person_id" type="string" required>
  Author identifier.
</ParamField>

<ParamField query="plot" type="string" required>
  Must be `author_coauthorship_network`.
</ParamField>

It also accepts the [product filters](/en/api-reference/person/get-research-products). `max`, `page` and `sort` do not apply.

## Response

<ResponseField name="plot" type="object">
  <Expandable title="properties">
    <ResponseField name="nodes" type="object[]">
      Network nodes (up to 50, sorted by descending degree).
      <Expandable title="properties of each node">
        <ResponseField name="id" type="string">
          Author identifier.
        </ResponseField>
        <ResponseField name="label" type="string">
          Author name.
        </ResponseField>
        <ResponseField name="degree" type="integer">
          Number of connections of the node.
        </ResponseField>
        <ResponseField name="size" type="float">
          Visual size of the node, proportional to its relevance.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="edges" type="object[]">
      Edges between the nodes included in the response.
      <Expandable title="properties of each edge">
        <ResponseField name="source" type="string">
          Source node identifier.
        </ResponseField>
        <ResponseField name="target" type="string">
          Target node identifier.
        </ResponseField>
        <ResponseField name="coauthorships" type="integer">
          Number of co-authored products between the two authors.
        </ResponseField>
        <ResponseField name="size" type="float">
          Visual thickness of the edge.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
