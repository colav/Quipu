## Path parameters

<ParamField path="geo_type" type="string" required>
  Geographic entity type. Allowed values: `state` or `city`.
</ParamField>

<ParamField path="geo_id" type="string" required>
  DANE code of the entity. Examples: `05` for Antioquia, `05001` for
  Medellín.
</ParamField>

## Query parameters

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Sort with the format `field_direction`, where the direction is `asc` or
  `desc`. Fields for products: `citations`, `alphabetical` (by title) and
  `year` (publication year). Example: `year_desc`.
</ParamField>

<ViewParam />

<FieldsParam />

### Filters

The same filters as [Search products](/en/api-reference/search/works). All of them accept several values separated by commas.

<WorksFilterParams />

<Note>
  If you don't send `max`, `page` or `sort`, `max=10`, `page=1` and
  `sort=citations_desc` apply. If you send `max` and `page` without `sort`,
  `sort=citations_desc` applies.
</Note>
