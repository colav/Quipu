## Path parameters

<ParamField path="work_id" type="string" required>
  Product identifier, with its `/` unencoded. Example:
  `10.1016/s0140-6736(20)30925-9`. See [Product identifier](#product-identifier).
</ParamField>

## Product identifier

A product's identifier is the first of these external identifiers it has, in this order:

| Priority | Source | Example |
| --- | --- | --- |
| 1 | DOI, lowercase and without `https://doi.org/` | `10.1016/s0140-6736(20)30925-9` |
| 2 | OpenAlex | `W1000532232` |
| 3 | ScienTI (`COD_RH-COD_PRODUCTO`) | `0000000004-1` |
| 4 | Minciencias | `ART-0000141429-480` |
| 5 | Handle of the institutional repository | `20.500.11761/31359` |
| 6 | DSpace OAI identifier, if the repository has no registered handle | `oai:bibliotecadigital.univalle.edu.co:item/486` |
| 7 | ISBN, books only | `9781420053418` |
| 8 | Google Scholar | `zKy1aB2cXsJ` |
| 9 | Internal identifier of 24 hexadecimal characters, if it has none of the above | `6ab4ac4e5418a51e324cc06a` |

- **The identifier can contain `/`** (DOI and handle). Send them unencoded: `%2F` returns `404`. Other special characters (`( ) < > ; : # ? %`) are encoded: `#` → `%23`, `?` → `%3F`, `%` → `%25`.
- **Suffixes `-000`, `-001`…:** when several products share the same identifier (duplicates that were not merged, or chapters carrying the DOI of their book), each one gets a three-digit suffix, for example `10.1111/bij.12406-000`. The suffix is part of the identifier. To see every product of a DOI use [Find a product by DOI](/en/api-reference/work/get-work-by-doi).
- **DOI cleaning:** the identifier carries no URLs glued to the DOI, no `//` and no trailing `/`. The DOI as the source gives it stays in `external_ids`.
- The identifier is kept across database updates, unless the product receives a higher-priority identifier (for example, a DOI) or its group of duplicates changes. Copy the `id` returned by the searches instead of building it.

## Response

<ResponseField name="data" type="object">
  The requested product.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Product identifier.
    </ResponseField>
    <ResponseField name="title" type="string">
      Main title.
    </ResponseField>
    <ResponseField name="titles" type="object[]">
      Titles by source (`title`, `lang`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="subtitle" type="string | null">
      Subtitle.
    </ResponseField>
    <ResponseField name="language" type="string">
      Language (ISO 639-1 code).
    </ResponseField>
    <ResponseField name="year_published" type="integer">
      Publication year.
    </ResponseField>
    <ResponseField name="date_published" type="integer | null">
      Publication date in Unix seconds.
    </ResponseField>
    <ResponseField name="doi" type="string | null">
      Full DOI (for example `https://doi.org/10.1000/xyz`).
    </ResponseField>
    <ResponseField name="keywords" type="array">
      Keywords.
    </ResponseField>
    <ResponseField name="abstract" type="string | null">
      Main abstract as text.
    </ResponseField>
    <ResponseField name="authors" type="object[]">
      All the authors of the product, in signing order (10 with
      `view=summary`), with their affiliations, external identifiers,
      classifications and available demographic data. See [Product authors](/en/guides/authorship).
    </ResponseField>
    <ResponseField name="authors_count" type="integer">
      Number of authors.
    </ResponseField>
    <ResponseField name="groups" type="object[]">
      Associated research groups, with their citations and classifications.
    </ResponseField>
    <ResponseField name="product_types" type="object[]">
      Product types by source (`name`, `source`).
    </ResponseField>
    <ResponseField name="types" type="object[]">
      Types by source with level and classification.
    </ResponseField>
    <ResponseField name="ranking" type="object[]">
      Product classifications (for example, from Minciencias).
    </ResponseField>
    <ResponseField name="source" type="object">
      Source (journal or other type) where it was published. It includes `id`, `name`,
      `names`, `types`, `external_ids`, `external_urls`, `ranking`,
      `publisher`, `apc`, `scimago_quartile` and `updated`.
    </ResponseField>
    <ResponseField name="bibliographic_info" type="object">
      Bibliographic information: `volume`, `issue`, `start_page`, `end_page`,
      `pages` and `bibtex`.
    </ResponseField>
    <ResponseField name="bibtex" type="string | null">
      BibTeX entry.
    </ResponseField>
    <ResponseField name="volume" type="string | integer | null">
      Volume. Copy of `bibliographic_info.volume`.
    </ResponseField>
    <ResponseField name="pages" type="string | null">
      Pages. Copy of `bibliographic_info.pages`.
    </ResponseField>
    <ResponseField name="start_page" type="string | null">
      Start page. Copy of `bibliographic_info.start_page`.
    </ResponseField>
    <ResponseField name="end_page" type="string | null">
      End page. Copy of `bibliographic_info.end_page`.
    </ResponseField>
    <ResponseField name="publisher" type="string | null">
      Name of the publisher.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citations by source (`count`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="citations_by_year" type="object[]">
      Citations per year (`year`, `cited_by_count`).
    </ResponseField>
    <ResponseField name="open_access" type="object">
      Open access status: `is_open_access`, `open_access_status`,
      `url` and `has_repository_fulltext`.
    </ResponseField>
    <ResponseField name="apc" type="object">
      APC information: `charges`, `currency` and `paid`.
    </ResponseField>
    <ResponseField name="primary_topic" type="object">
      Primary topic with its subfield, field and domain (OpenAlex).
    </ResponseField>
    <ResponseField name="topics" type="object[]">
      Associated topics.
    </ResponseField>
    <ResponseField name="subjects" type="object[]">
      Subject areas grouped by source.
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      External identifiers.
    </ResponseField>
    <ResponseField name="external_urls" type="object[]">
      External links: DOI, Scholar, open access, etc.
    </ResponseField>
    <ResponseField name="references" type="array">
      Bibliographic references.
    </ResponseField>
    <ResponseField name="references_count" type="integer | null">
      Number of references.
    </ResponseField>
    <ResponseField name="updated" type="object[]">
      Last update by source (`source`, `time` in Unix seconds).
    </ResponseField>
  </Expandable>
</ResponseField>
