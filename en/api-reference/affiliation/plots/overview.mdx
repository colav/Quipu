With the `plot` parameter, the [Affiliation products](/en/api-reference/affiliation/get-research-products) endpoint returns an indicator instead of the product list.

```text
GET /affiliation/{affiliation_type}/{affiliation_id}/research/products?plot=<indicator>
```

Indicators accept the same filters as the product list.
