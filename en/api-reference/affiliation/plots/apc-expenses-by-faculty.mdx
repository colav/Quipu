Distribution of APC expenses among faculties. Chart type: **Pie**.

## Parameters

<ParamField path="affiliation_type" type="string" required>
  Affiliation type. This indicator returns data for: `institution`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Affiliation identifier.
</ParamField>

<ParamField query="plot" type="string" required>
  Must be `apc_expenses_by_faculty`.
</ParamField>

It also accepts the [product filters](/en/api-reference/affiliation/get-research-products). `max`, `page` and `sort` do not apply.

## Availability by affiliation type

| `affiliation_type` | Data |
| --- | --- |
| `institution` | ✅ |
| `faculty` | No data |
| `department` | No data |
| `group` | No data |
