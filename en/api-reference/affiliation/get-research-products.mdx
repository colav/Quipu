This endpoint has two modes:

- **Product list** (without `plot`): returns the affiliation's products, with pagination, sorting and filters.
- **Indicators** (with `plot`): returns the data of one of the affiliation's indicators. See the [indicator catalogue](/en/api-reference/affiliation/plots/overview).

## Path parameters

<ParamField path="affiliation_type" type="string" required>
  Affiliation type: `institution`, `faculty`, `department` or `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Affiliation identifier. Examples: `03bp5hc83` (institution),
  `03bp5hc83_20` (faculty).
</ParamField>

## Query parameters

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Sort with the format `field_direction`, where the direction is `asc` or
  `desc`. Fields for products: `citations`, `alphabetical` (by title) and
  `year` (publication year). Example: `year_desc`.
</ParamField>

<ViewParam />

<FieldsParam />

<ParamField query="plot" type="string">
  Name of the indicator to return. With this parameter the response is the
  indicator, without pagination. See the [indicator
  catalogue](/en/api-reference/affiliation/plots/overview).
</ParamField>

### Filters

The same filters as [Search products](/en/api-reference/search/works). They also apply to indicators. All of them accept several values separated by commas.

<WorksFilterParams />

The valid options can be looked up in [Affiliation product filters](/en/api-reference/affiliation/get-research-products-filters).

<Note>
  If you don't send `max`, `page` or `sort`, `max=10`, `page=1` and
  `sort=citations_desc` apply. If you send `max` and `page` without `sort`,
  `sort=citations_desc` applies.
</Note>
