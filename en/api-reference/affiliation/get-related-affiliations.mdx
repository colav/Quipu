---
title: "Related affiliations"
api: "GET https://api.dev.impactu.colav.co/affiliation/{affiliation_type}/{affiliation_id}/affiliations"
description: "Returns the faculties, departments, groups and authors associated with an affiliation."
---

## Path parameters

<ParamField path="affiliation_type" type="string" required>
  Affiliation type: `institution`, `faculty`, `department` or `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Affiliation identifier. Examples: `03bp5hc83` (institution),
  `03bp5hc83_2` (faculty), `03bp5hc83_2_21620001_3153` (department),
  `COL0000407` (group).
</ParamField>

<Note>
  This endpoint takes no query parameters. Unlike [Get an
  affiliation](/en/api-reference/affiliation/get-affiliation), the response is not
  wrapped in `data`.
</Note>

## Response

The response is an object whose lists depend on the type of the requested affiliation:

| `affiliation_type` | `faculties` | `departments` | `groups` | `authors` |
| ------------------ | :---------: | :-----------: | :------: | :-------: |
| `institution`      |     ✅      |      ✅       |    ✅    |           |
| `faculty`          |             |      ✅       |    ✅    |    ✅     |
| `department`       |             |               |    ✅    |    ✅     |
| `group`            |             |               |          |    ✅     |

An institution without faculties or departments also includes `authors`. If the affiliation doesn't exist, or the type is not one of the four, the response is `200` with empty lists.

<ResponseField name="faculties" type="object[]">
  Faculties of the institution.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Faculty identifier.
    </ResponseField>
    <ResponseField name="name" type="string">
      Name.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="departments" type="object[]">
  Departments. Same structure as `faculties`.
</ResponseField>

<ResponseField name="groups" type="object[]">
  Research groups. Same structure as `faculties`.
</ResponseField>

<ResponseField name="authors" type="object[]">
  Associated authors.
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Author identifier.
    </ResponseField>
    <ResponseField name="full_name" type="string">
      Full name.
    </ResponseField>
  </Expandable>
</ResponseField>
