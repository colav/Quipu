This endpoint has two modes:

- **Product export** (without `plot`): downloads a CSV with all the affiliation's products, applying the active filters.
- **Indicator export** (with `plot`): downloads a CSV with the data of the given indicator instead of the product list.

## Path parameters

<ParamField path="affiliation_type" type="string" required>
  Affiliation type: `institution`, `faculty`, `department` or `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Affiliation identifier.
</ParamField>

## Query parameters

<ParamField query="plot" type="string">
  Name of the indicator to export. With this parameter the indicator's CSV is
  downloaded instead of the product list. See the [indicator
  catalogue](/en/api-reference/affiliation/plots/overview).
</ParamField>

### Filters

The same filters as [Search products](/en/api-reference/search/works). They also
apply when `plot` is used.
