Returns the values you can use in the filters of [Affiliation products](/en/api-reference/affiliation/get-research-products). They are the same filters as [Search products](/en/api-reference/search/works-filters), but computed only over the products of the given affiliation.

The options and their counts depend on the filters you send: if you apply a filter, only the options that exist within that result are returned.

## Path parameters

<ParamField path="affiliation_type" type="string" required>
  Affiliation type: `institution`, `faculty`, `department` or `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Affiliation identifier. Examples: `03bp5hc83` (institution),
  `03bp5hc83_20` (faculty).
</ParamField>

## Query parameters

All are optional. They accept several values separated by commas.
