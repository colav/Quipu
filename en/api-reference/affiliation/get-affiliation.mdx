---
title: "Get an affiliation"
api: "GET https://api.dev.impactu.colav.co/affiliation/{affiliation_type}/{affiliation_id}"
description: "Returns an affiliation (institution, faculty, department or group) from its identifier."
---

import ViewParam from "/snippets/en/view-param.mdx";
import EntityMeta from "/snippets/en/entity-meta.mdx";

## Path parameters

<ParamField path="affiliation_type" type="string" required>
  Affiliation type: `institution`, `faculty`, `department` or `group`.
</ParamField>

<ParamField path="affiliation_id" type="string" required>
  Affiliation identifier. Examples: `03bp5hc83` (institution),
  `03bp5hc83_20` (faculty), `03bp5hc83_2_21620003_3154` (department),
  `COL0001262` (group).
</ParamField>

## Query parameters

<ViewParam />

`max`, `page` and `sort` do not apply.

<Note>
  The API does not validate `affiliation_type`: it returns the affiliation that
  matches `affiliation_id` with any type, even if it doesn't match or doesn't
  exist. For example, `/affiliation/faculty/03bp5hc83` returns the institution,
  without an error. Use the right type: the parent affiliations included in
  `affiliations` depend on it.
</Note>

## Response

<ResponseField name="data" type="object">
  The requested affiliation.
  <Expandable title="properties">
    <ResponseField name="_id" type="string">
      Affiliation identifier.
    </ResponseField>
    <ResponseField name="name" type="string | null">
      Main name (in Spanish if there is one).
    </ResponseField>
    <ResponseField name="names" type="object[]">
      Names by source (`name`, `lang`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="abbreviations" type="string[]">
      Acronyms and short names.
    </ResponseField>
    <ResponseField name="aliases" type="string[]">
      Alternative names.
    </ResponseField>
    <ResponseField name="types" type="object[]">
      Affiliation types by source (`type`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="addresses" type="object[]">
      Addresses: `city`, `state`, `country`, `country_code`, `postcode`,
      `lat`, `lng`.
    </ResponseField>
    <ResponseField name="year_established" type="integer | null">
      Year founded.
    </ResponseField>
    <ResponseField name="description" type="object[]">
      Descriptions by source. For groups it includes texts such as state of the
      art, objectives, work plan, highlighted output, challenges and vision.
    </ResponseField>
    <ResponseField name="products_count" type="integer">
      Number of products.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citations by source (`count`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="h_index" type="integer | null">
      H-index.
    </ResponseField>
    <ResponseField name="h5_index" type="integer | null">
      H-index of the last 5 years.
    </ResponseField>
    <ResponseField name="ranking" type="object[]">
      Classifications, for example a group's (`rank`, `source`,
      `from_date`, `to_date`).
    </ResponseField>
    <ResponseField name="affiliations" type="object[]">
      Direct parent affiliations (for example, the institution of a
      faculty).
    </ResponseField>
    <ResponseField name="relations" type="object[]">
      Related affiliations: the parents and, for faculties, also their
      departments and units (`id`, `name`, `types`, `external_urls`).
    </ResponseField>
    <ResponseField name="subjects" type="object[]">
      Subject areas grouped by source (for example, OECD for groups).
    </ResponseField>
    <ResponseField name="status" type="array">
      Status. It can be a list of strings (institutions) or of objects with
      `source` and `status` (groups).
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      External identifiers (ROR, OpenAlex, SNIES, Scienti, Minciencias,
      among others).
    </ResponseField>
    <ResponseField name="external_urls" type="object[]">
      External links (website, Wikipedia, OpenAlex, ROR).
    </ResponseField>
    <ResponseField name="updated" type="object[]">
      Last update by source (`source`, `time` in Unix seconds).
    </ResponseField>
  </Expandable>
</ResponseField>

<EntityMeta />

The identifier comes in `_id`, not in `id` as in the other entities. With `view=summary`, fields without data are left out.

### Differences by type

| Field          | Institution     | Faculty                      | Department                      | Group                 |
| -------------- | --------------- | ---------------------------- | ------------------------------- | --------------------- |
| `affiliations` | empty           | the institution              | the institution and the faculty | the institution       |
| `relations`    | empty           | institution and departments  | institution and faculty         | institution           |
| `description`  | empty           | empty                        | empty                           | the group's texts     |
| `ranking`      | no useful data  | empty                        | empty                           | group classification  |
