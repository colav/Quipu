## Path parameters

<ParamField path="affiliation_type" type="string" required>
  Type of affiliation to search: `institution`, `faculty`, `department` or `group`.
</ParamField>

## Query parameters

<ParamField query="keywords" type="string">
  Search text (affiliation name).
</ParamField>

<PaginationParams />

<ParamField query="sort" type="string" default="citations_desc">
  Sort with the format `field_direction`, where the direction is `asc` or
  `desc`. Fields for affiliations: `products` (most output), `citations`
  (most citations), `h` (h-index) and `h5` (h5-index). Example: `products_desc`.
</ParamField>

<ViewParam />

### Filters

The three filters accept several values separated by commas.

<ParamField query="states" type="string">
  Departments of the affiliation's address. The normalized values are used
  and their variants in the database are included. Example:
  `Antioquia,Tolima`.
</ParamField>

<ParamField query="cities" type="string">
  Cities of the affiliation's address. Variants such as "Bogotá, D.C." or
  "Santiago de Cali" are also included. Example: `Bogotá,Cali`.
</ParamField>

<ParamField query="groups_ranking" type="string">
  Current classification of the group. It is compared with the most recent ranking (by
  `from_date`), whatever its source. Example: `A1,A2`.
</ParamField>

<Note>
  If you don't send `max`, `page` or `sort`, `max=10`, `page=1` and
  `sort=citations_desc` apply. If you send `max` and `page` without `sort`,
  `sort=citations_desc`. With `affiliation_type=institution` all institution
  types are included.
</Note>

## Response

<ResponseField name="data" type="array">
  List of affiliations.
  <Expandable title="properties of each affiliation">
    <ResponseField name="id" type="string">
      Affiliation identifier.
    </ResponseField>
    <ResponseField name="name" type="string | null">
      Main name (in Spanish if there is one).
    </ResponseField>
    <ResponseField name="names" type="object[]">
      Names by source (`name`, `lang`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="abbreviations" type="string[]">
      Acronyms.
    </ResponseField>
    <ResponseField name="aliases" type="string[]">
      Alternative names.
    </ResponseField>
    <ResponseField name="types" type="object[]">
      Affiliation types by source (`type`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="addresses" type="object[]">
      Addresses: `city`, `state`, `country`, `country_code`, `postcode`,
      `lat`, `lng`.
    </ResponseField>
    <ResponseField name="year_established" type="integer | null">
      Year founded.
    </ResponseField>
    <ResponseField name="description" type="object[]">
      Descriptions by source.
    </ResponseField>
    <ResponseField name="products_count" type="integer">
      Number of products.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citations by source (`count`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="h_index" type="integer | null">
      H-index.
    </ResponseField>
    <ResponseField name="h5_index" type="integer | null">
      H-index of the last 5 years.
    </ResponseField>
    <ResponseField name="ranking" type="object[]">
      Classifications (for example, a research group's).
    </ResponseField>
    <ResponseField name="affiliations" type="object[] | null">
      Direct parent affiliations (for example, the institution of a
      faculty). In the search it can come as `null`.
    </ResponseField>
    <ResponseField name="relations" type="object[]">
      Related affiliations (`id`, `name`, `types`, `external_urls`). For
      example, the institution and the departments of a faculty.
    </ResponseField>
    <ResponseField name="subjects" type="object[]">
      Subject areas.
    </ResponseField>
    <ResponseField name="status" type="array">
      Status of the affiliation.
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      External identifiers (`id`, `source`, `provenance`).
    </ResponseField>
    <ResponseField name="external_urls" type="object[]">
      External links.
    </ResponseField>
    <ResponseField name="updated" type="object[]">
      Last update by source (`source`, `time` in Unix seconds).
    </ResponseField>
  </Expandable>
</ResponseField>
