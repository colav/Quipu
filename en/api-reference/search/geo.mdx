---
title: "Search geographic entities"
api: "GET https://api.dev.impactu.colav.co/search/geo/{geo_type}"
description: "Paginated search of cities and departments of Colombia."
---

import PaginationParams from "/snippets/en/pagination-params.mdx";
import MetaResponse from "/snippets/en/meta-response.mdx";

## Path parameters

<ParamField path="geo_type" type="string" required>
  Geographic entity type: `city` (cities) or `state` (departments).
  Any other value returns a 400 error.
</ParamField>

## Query parameters

<ParamField query="keywords" type="string">
  Search text (name of the city or department).
</ParamField>

<PaginationParams />

<ParamField query="sort" type="string">
  Sort with the format `field_direction`, where the direction is `asc` or
  `desc`. For geographic entities, `alphabetical` sorts by name. Example:
  `alphabetical_asc`.
</ParamField>

<Note>This endpoint has no filters.</Note>

## Response

The structure changes with `geo_type`. The common fields are:

<ResponseField name="data" type="array">
  List of geographic entities.
  <Expandable title="properties of each entity">
    <ResponseField name="id" type="string">
      Identifier (DANE code).
    </ResponseField>
    <ResponseField name="name" type="string">
      Name.
    </ResponseField>
    <ResponseField name="type" type="string">
      `city` or `state`.
    </ResponseField>
    <ResponseField name="country" type="string">
      Country.
    </ResponseField>
    <ResponseField name="country_code" type="string">
      Country code (for example, `CO`).
    </ResponseField>
    <ResponseField name="external_ids" type="object[]">
      External identifiers (`id`, `source`), such as the DANE code.
    </ResponseField>
    <ResponseField name="authors_count" type="integer">
      Number of authors.
    </ResponseField>
    <ResponseField name="groups_count" type="integer">
      Number of research groups.
    </ResponseField>
    <ResponseField name="institutions_count" type="integer">
      Number of institutions.
    </ResponseField>
    <ResponseField name="products_count" type="integer">
      Number of products.
    </ResponseField>
    <ResponseField name="citations_count" type="object[]">
      Citations by source (`count`, `source`).
    </ResponseField>
    <ResponseField name="state" type="object">
      Only with `city`: the department it belongs to (`id`, `name`).
    </ResponseField>
    <ResponseField name="latitude" type="number">
      Only with `city`: latitude.
    </ResponseField>
    <ResponseField name="longitude" type="number">
      Only with `city`: longitude.
    </ResponseField>
    <ResponseField name="cities_count" type="integer">
      Only with `state`: number of cities.
    </ResponseField>
  </Expandable>
</ResponseField>
