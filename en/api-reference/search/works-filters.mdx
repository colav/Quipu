Returns the values you can use in the filters of [Search products](/en/api-reference/search/works).
The options and their counts depend on the filters you send: if you apply a filter, only the options that exist within that result are returned.

## Query parameters

All are optional and work the same as in [Search products](/en/api-reference/search/works). They accept several values separated by commas.
