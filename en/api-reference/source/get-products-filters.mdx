Returns the values you can use in the filters of [Source products](/en/api-reference/source/get-products). They are the same filters as [Search products](/en/api-reference/search/works-filters), but computed only over the products published in the given source.

The options and their counts depend on the filters you send: if you apply a filter, only the options that exist within that result are returned.

## Path parameters

<ParamField path="source_id" type="string" required>
  Source identifier. Example: `6aad68732be7843cde64e41b`.
</ParamField>

## Query parameters

All are optional. They accept several values separated by commas.
