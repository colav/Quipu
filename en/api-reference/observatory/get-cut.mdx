---
title: "Cut-off dates of an observatory"
api: "GET https://api.dev.impactu.colav.co/observatories/{slug}/cut"
description: "Returns the cut-off dates of the loaded data and of each source, with the footer text of the boards."
---

<Note>
  It reads the same ClickHouse tables as
  [Board data](/en/api-reference/observatory/get-bundle): without them it
  returns `503`. It requires no authentication.
</Note>

## Path parameters

<ParamField path="slug" type="string" required>
  Observatory. Only `vri-udea` exists today.
</ParamField>

## Response

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="load_id" type="integer">
      Identifier of the load, shaped like a date (`20261107`).
    </ResponseField>
    <ResponseField name="cargado_en" type="string">
      Date of the load, in ISO 8601 UTC.
    </ResponseField>
    <ResponseField name="etl_desde" type="string">
      Start of the extraction of ImpactU data (`YYYY-MM-DD`).
    </ResponseField>
    <ResponseField name="etl_hasta" type="string">
      End of the extraction of ImpactU data.
    </ResponseField>
    <ResponseField name="texto" type="string">
      Footer text of the boards, built from `etl_hasta`.
    </ResponseField>
    <ResponseField name="ods_consultado" type="string">
      Date the SDG classification was queried.
    </ResponseField>
    <ResponseField name="v2_consultado" type="string">
      Date the OpenAlex topics were queried.
    </ResponseField>
    <ResponseField name="staff_fecha_ref" type="string">
      Reference date of the staff roster.
    </ResponseField>
    <ResponseField name="fuentes" type="object[]">
      Data sources: `clave`, `nombre`, `fecha_corte` (empty if the source
      declares none), `detalle` and `tableros`, the list of boards that use
      it.
    </ResponseField>
  </Expandable>
</ResponseField>
