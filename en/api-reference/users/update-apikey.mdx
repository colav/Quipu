---
title: "Update API key expiration"
api: "PATCH https://api.dev.impactu.colav.co/users/{email}/apikey"
description: "Updates the expiration date of the user's existing API key."
---

<Note>
  The authenticated user can only modify their own API key. If they don't
  have one yet, it returns `404`: create it first with
  [Generate API key](/en/api-reference/users/create-apikey).
</Note>

## Path parameters

<ParamField path="email" type="string" required>
  User's email address. It must match the authenticated user.
</ParamField>

## Request body

<ParamField body="expires" type="integer">
  New expiration date in Unix seconds, as an integer. It must be a
  future date at least 1 day ahead. If omitted, the API key has no
  expiration.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` if the expiration was updated successfully.
</ResponseField>

<ResponseField name="msg" type="string">
  Confirmation or error message.
</ResponseField>

<ResponseExample>
```json 200
{ "success": true, "msg": "Expiración del API key actualizada" }
```

```json 400
{ "success": false, "msg": "La expiración mínima del API key es de 1 día" }
```

```json 401
{"msg": "Token no proporcionado o inválido. Por favor, inicia sesión nuevamente.", "success": false}
```

```json 403
{ "success": false, "msg": "No tienes permiso para gestionar el API Key de otro usuario." }
```

```json 404
{ "success": false, "msg": "Usuario usuario@example.com no encontrado o sin API key" }
```
</ResponseExample>
