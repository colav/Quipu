---
title: "Reset password"
api: "PATCH https://api.dev.impactu.colav.co/admin/users/{email}"
description: "Generates a new random password for the user and sends it by email."
---

<Note>
  Requires an active session with the `admin` role. No body is sent in the
  request. The new password is sent to the user's email before it is
  saved: if the email cannot be sent, it returns `502` and the old
  password keeps working.
</Note>

## Path parameters

<ParamField path="email" type="string" required>
  Email address of the user whose password will be reset.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` if the password was reset and the email sent.
</ResponseField>

<ResponseField name="msg" type="string">
  Confirmation or error message.
</ResponseField>

<ResponseExample>
```json 200
{ "success": true, "msg": "La contraseña de usuario@example.com se actualizó correctamente." }
```

```json 404
{ "success": false, "msg": "El usuario con correo usuario@example.com no fue encontrado" }
```

```json 403 — deactivated account
{ "success": false, "msg": "Cuenta desactivada para el usuario usuario@example.com" }
```

```json 401
{"msg": "Token no proporcionado o inválido. Por favor, inicia sesión nuevamente.", "success": false}
```

```json 403
{ "success": false, "msg": "Permiso denegado: No pueden realizar esta acción." }
```

```json 502
{ "success": false, "msg": "No se pudo enviar el correo con las credenciales. No se guardó ningún cambio." }
```
</ResponseExample>
