## Your first query

Interact with ImpactU through HTTP requests
and receive structured JSON responses.

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://api.dev.impactu.colav.co/search/works?max=10&page=1&authors_count=-10" \
  --header "Accept: application/json"
```

```python Python
import requests

url = "https://api.dev.impactu.colav.co/search/works?max=10&page=1&authors_count=-10"

response = requests.get(
    url,
    headers={"Accept": "application/json"},
    timeout=30,
)

response.raise_for_status()

data = response.json()
print(data)
```

</CodeGroup>
